# A Computational and Conformal Analysis of Multibrot Sets

This repository contains the latest version of my research paper, *A Computational and Conformal Analysis of Multibrot Sets*.

## Abstract

This paper investigates generalized Multibrot sets generated by the polynomial family \(z \mapsto z^d + c\) for arbitrary integer degrees \(d \ge 2\). It presents numerical methods for approximating Multibrot set areas and studying their convergence, proves rotational and reflection symmetries, analyzes boundary morphology as the polynomial degree increases, and develops a recursive framework for computing Laurent coefficients of the exterior conformal map. Computational results are validated using the Gronwall Area Theorem and compared with existing results for the classical Mandelbrot set.

## Topics

- Numerical area approximation and convergence
- Rotational and reflection symmetries
- Boundary morphology
- Laurent coefficient computation
- Exterior conformal mapping
- Gronwall Area Theorem validation
- Computational complex dynamics
